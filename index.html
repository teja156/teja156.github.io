TubeMatic

A self-hosted pipeline that turns a topic into a finished YouTube Short.

It researches the topic, writes the script, voices it, generates imagery, and animates every scene as a React component that an AI agent writes for that specific video. Remotion renders the mp4, then an AI watches the result for defects. It waits at three checkpoints for a human to approve before money is spent or a video goes out, or you can hand those approvals to Auto Pilot.

You run it from a web dashboard on your own Linux machine with Docker, and you can read exactly what produced any frame.
